# Review Analyzer — анализ тональности отзывов

Консольное приложение на Python для автоматического определения тональности текстовых отзывов с помощью предобученных моделей [Hugging Face](https://huggingface.co/). Программа не обучает нейросеть самостоятельно, а использует готовые модели через библиотеку `transformers`.

Проект выполнен в рамках практической работы по анализу тональности текста.

## Возможности

- Анализ одного отзыва, введённого с клавиатуры.
- Проверка пустого ввода.
- Загрузка и автоматический анализ отзывов из `reviews.txt` (один отзыв на строку).
- Вывод метки тональности и оценки уверенности модели.
- Подсчёт положительных, отрицательных и нейтральных отзывов.
- Сравнение двух моделей на одинаковом наборе отзывов.
- Сохранение результатов и статистики в `results.txt`.
- Обработка отсутствующего файла отзывов и ошибок записи результатов.

## Используемые модели

1. [`tabularisai/multilingual-sentiment-analysis`](https://huggingface.co/tabularisai/multilingual-sentiment-analysis) — многоязычная модель с пятью классами: `Very Negative`, `Negative`, `Neutral`, `Positive`, `Very Positive`.
2. [`cardiffnlp/twitter-roberta-base-sentiment-latest`](https://huggingface.co/cardiffnlp/twitter-roberta-base-sentiment-latest) — модель с тремя классами: `negative`, `neutral`, `positive`, предназначенная прежде всего для англоязычных текстов.

Для статистики и сравнения метки приводятся к трём категориям: **положительная**, **отрицательная**, **нейтральная**. Сравнение показывает совпадение предсказаний, **а не точность** моделей: для измерения точности нужны заранее размеченные правильные ответы.

## Установка и запуск

Требуется установленный Python. Проект разрабатывался в Windows с использованием виртуального окружения `.venv`.

1. Склонировать репозиторий и перейти в его каталог:

   ```powershell
   git clone <URL-РЕПОЗИТОРИЯ>
   cd Review_Analyzer_Py
   ```

   Если проект уже находится на компьютере, просто откройте его папку в терминале.

2. Создать и активировать виртуальное окружение (PowerShell):

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. Установить зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Запустить приложение:

   ```powershell
   python main.py
   ```

При первом запуске модели загружаются с Hugging Face; потребуется подключение к интернету. Затем скачанные файлы обычно используются из локального кеша. Вторая модель загружается при выборе режима сравнения.

## Меню программы

```text
1. Ручной анализ одного отзыва
2. Анализ отзывов из файла
3. Сравнение двух моделей
0. Выход
```

В `reviews.txt` каждый непустой ряд считается отдельным отзывом. Для сравнения модели обрабатывают один и тот же список. Для отдельного эксперимента можно использовать `test_reviews.txt`, изменив имя файла в функции `comparison_analysis()`.

## Результаты экспериментов

В выполненном учебном эксперименте:

| Набор отзывов | Всего | Совпадений | Несовпадений | Доля совпадений |
|---|---:|---:|---:|---:|
| Основной | 40 | 33 | 7 | 82,5% |
| Дополнительный (короткие, длинные, саркастические и противоречивые) | 10 | 7 | 3 | 70% |

Пример расхождения: на отзыве `Fantastic! The app crashed five times today.` первая модель определила отрицательную тональность, а вторая — положительную. Это показывает, что сарказм может приводить к ошибкам классификации.

Оценка уверенности (`score`) — это показатель, выдаваемый моделью, а не гарантия правильности её ответа.

## Используемые библиотеки

- `transformers` — загрузка моделей и анализ текста через `pipeline`.
- `torch` — запуск нейросетевых вычислений.
- `sentencepiece` — библиотека токенизации, установленная для совместимости с моделями/токенизаторами.

Стандартная библиотека Python `datetime` используется для сохранения даты и времени анализа.
